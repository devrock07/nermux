# eDEX-UI Asset Notes

Nermux includes a small set of UI sound effects adapted from the archived
`gitsquared/edex-ui` project.

- Source: https://github.com/GitSquared/edex-ui
- License: GPL-3.0
- Imported files: `keyboard.wav`, `panels.wav`, `scan.wav`, `granted.wav`, `error.wav`

The sounds are used only as low-volume Android UI feedback for the native
Nermux terminal cockpit.
